# Student Performance Dashboard

A beginner-friendly HTML, CSS and JavaScript dashboard for managing existing student performance data.

## Structure

- `index.html` — application entry point
- `components/` — reusable page parts
- `pages/` — UI structure for each dashboard page
- `css/style.css` — responsive styling
- `js/data.js` — existing sample data
- `js/calculations.js` — calculations and statistics
- `js/app.js` — page navigation, rendering data, search and interactions

## Run

Because the project loads HTML files with `fetch()`, run it through a local server.

In VS Code:
1. Open the project folder.
2. Install/use Live Server.
3. Right-click `index.html`.
4. Choose **Open with Live Server**.

Do not open `index.html` directly with `file://`.

## Current scope

The project assumes that student and assignment data already exists. There are no data-entry forms yet.

Login/authentication and backend/database integration can be added later.
